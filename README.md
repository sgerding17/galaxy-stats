See https://sgerding17.github.io/galaxy-stats for stats.

To log a game from a phone as it happens, open
https://sgerding17.github.io/galaxy-stats/logger/ and see
[docs/logger/README.md](docs/logger/README.md).

To follow a game while it is being logged, open
https://sgerding17.github.io/galaxy-stats/live/. It reads the running game from a
small Cloudflare Worker; see [worker/README.md](worker/README.md) to deploy one.

To generate a draft game log from game video, see [video2log/README.md](video2log/README.md).
